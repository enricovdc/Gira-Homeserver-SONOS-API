1.Beschreibung

Einzelinstanz-Begleitbaustein, der einen HTTP-Server innerhalb von HSL3 startet und eine Web-Administrationsoberflaeche fuer die Sonos-Integration bereitstellt. Die UI verwaltet automatisch gefundene und manuell hinzugefuegte Sonos-Player (per IP und/oder MAC), eine globale Preset-Bibliothek und die Sonos Cloud Control API Zugangsdaten mit OAuth-Autorisierung direkt vom HomeServer aus.
Der Baustein fuehrt sowohl periodische als auch KNX-ausloesbare SSDP-Suchen aus. Das letzte Suchergebnis wird als zeilenweise Liste ip;uuid;model am Ausgang DiscoveredPlayers und als Anzahl am Ausgang LastDiscoveryCount bereitgestellt.
Der Baustein fuehrt ein klassenweites Player-Register, das LBS 22000 Sonos Player nutzt, wenn dessen Host-Eingang ein Name oder eine MAC-Adresse statt einer IP ist. Damit bleiben konfigurierte Player-Referenzen auch bei DHCP-Adresswechsel stabil.
Hinweis
LBS 22000 funktioniert auch ohne diesen Admin-Baustein, dann allerdings nur mit fester IP. Fuegen Sie den Admin-Baustein hinzu, um die Web-UI, KNX-ausloesbare Suche, die gemeinsame Preset-Liste oder DHCP-feste Player-Referenzen zu bekommen.
Wichtig
Der Baustein oeffnet TCP-Port 8080 (oder den naechsten freien bis 8083). Die Web-UI ist nicht authentifiziert und sollte nur im lokalen Netzwerk erreichbar sein.
