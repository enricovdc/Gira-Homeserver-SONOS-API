1.Beschreibung

Steuert einen einzelnen Sonos Player ueber das lokale Netzwerk mittels der UPnP und SOAP API auf Port 1400. Bietet Wiedergabesteuerung (Play, Pause, Stop, Naechster, Vorheriger), Lautstaerke und Stummschaltung, acht konfigurierbare Radiosender, Statusausgaenge (Zustand, Lautstaerke, Stumm, Titel, Interpret, aktiver Sender) und Live UPnP Event Push so dass Statusausgaben ohne Polling aktualisiert werden.
Kompatibel mit aktueller und 2026er Sonos Firmware. Der Radiosenderstart verwendet leere DIDL-Lite Metadaten und das x-rincon-mp3radio Direkt-Broadcast-Schema mit automatischem Fallback bei Ablehnung.
Wichtig
Der Baustein oeffnet einen TCP Listener auf Port 8081 (oder dem naechsten freien Port bis 8083) fuer den Empfang von UPnP NOTIFY Callbacks. Der HomeServer muss diesen Port am LAN Interface erlauben. Bei Fehlschlag schaltet der Baustein auf Timer-basiertes Status-Polling um und funktioniert weiterhin.
Hinweis
Fuegen Sie eine Instanz pro Sonos Player hinzu. Jede Instanz benoetigt einen eindeutigen Host. Alle Instanzen teilen sich einen NOTIFY Listener Thread.

2.Eingaenge

E#NameInitBeschreibung
E1HostPlayer-Kennung. UUID (z.B. RINCON_xxx) wird dringend empfohlen, da diese auch ueber Firmware-Updates und DHCP-Adresswechsel stabil bleibt. MAC-Adresse, eigener Name aus dem Admin-Baustein oder eine literale IPv4 werden ebenfalls akzeptiert. Pflichtfeld.
E2Play0Steigende Flanke startet oder setzt Wiedergabe fort.
E3Pause0Steigende Flanke pausiert.
E4Stop0Steigende Flanke stoppt.
E5Next0Naechster Titel.
E6Prev0Vorheriger Titel.
E7SetVolume0Absolute Lautstaerke 0 bis 100.
E8VolUp0Lauter um VolStep.
E9VolDown0Leiser um VolStep.
E10SetMute00 unmute, nicht 0 mute.
E11MuteToggle0Schaltet Stummschaltung um.
E12StartRadio0Alphabetischer Index 1..N eines Senders aus der Sonos Admin Bibliothek. Die Spalte # in der Admin-UI zeigt den aktuellen Index.
E13StartRadioNameSendername (Gross-Klein-egal) aus der Sonos Admin Bibliothek. Praktisch fuer Bindung an Gira Visualisierungs-Auswahl oder Textfeld.
E14Resubscribe0Erneuert die UPnP Abonnements.
E14VolStep2Schrittweite fuer VolUp und VolDown.
E15PollInterval60Status-Abfrageintervall in Sekunden.
E16SubTimeout1800UPnP Abonnement Timeout.
E17HttpTimeout5HTTP Anfrage Timeout in Sekunden.
E18CallbackBaseCallback Basis URL. Leer fuer automatische Erkennung.
E19..E26Station1Uri..Station8UriStream URIs fuer Radiosender 1 bis 8.

3.Ausgaenge

A#NameInitSBCBeschreibung
A1ZoneNamejaSonos-Zonenname aus der Sonos-App (z.B. "Wohnzimmer"). Wird bei jedem Tick aus <roomName> des Players gelesen, so dass Umbenennungen aus der Sonos-App innerhalb eines Polling-Intervalls erscheinen.
A2Online0ja1 wenn der Player kuerzlich antwortete.
A3StatejaWiedergabestatus.
A4Volume0jaAktuelle Lautstaerke.
A5Mute0jaStummschaltung.
A6TitlejaTitel oder Stream-Inhalt.
A7ArtistjaInterpret.
A8ActiveStation0jaAktive Radiosender-Nummer.
A9LastErrorjaLetzter Fehlercode.
A10Subscribed0ja1 wenn beide UPnP Abonnements aktiv sind.
