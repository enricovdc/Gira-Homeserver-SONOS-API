1.Description

Controls one Sonos player over the local network using the players UPnP and SOAP API on port 1400. Provides playback control (play, pause, stop, next, previous), volume and mute, eight configurable radio stations, status outputs (state, volume, mute, title, artist, active station), and live UPnP event push so status outputs update without polling.
Compatible with current and 2026 Sonos firmware. The radio start path uses empty DIDL-Lite metadata and the x-rincon-mp3radio direct-broadcast scheme, with an automatic fallback if the player rejects the first attempt.
Important
The node binds a TCP listener on port 8081 (or the next free port up to 8083) to receive UPnP NOTIFY callbacks from the players. The HomeServer must allow this port on the LAN interface. If binding fails the node falls back to timer-based status polling and still works.
Note
Add one instance per Sonos player. Each instance must have a unique Host. All instances share one NOTIFY listener thread.

2.Inputs

E#NameInitDescription
E1HostPlayer identifier. UUID (e.g. RINCON_xxx) is strongly preferred because it is stable across firmware updates and DHCP renumbering. MAC address, custom name from the Admin block, or a literal IPv4 also accepted. Required.
E2Play0Rising edge starts or resumes playback.
E3Pause0Rising edge pauses playback.
E4Stop0Rising edge stops playback.
E5Next0Rising edge skips to next track.
E6Prev0Rising edge skips to previous track.
E7SetVolume0Absolute volume 0 to 100.
E8VolUp0Rising edge increases volume by VolStep.
E9VolDown0Rising edge decreases volume by VolStep.
E10SetMute00 unmutes, non-zero mutes.
E11MuteToggle0Rising edge toggles mute.
E12StartRadio0Station index 1 to 8 starts that station.
E13Resubscribe0Rising edge clears UPnP subscriptions and re-subscribes.
E14VolStep2Step size for VolUp and VolDown.
E15PollInterval60Status poll interval in seconds.
E16SubTimeout1800UPnP subscription timeout granted to the player.
E17HttpTimeout5HTTP request timeout in seconds.
E18CallbackBaseCallback base URL for UPnP. Leave empty for auto detection.
E19..E26Station1Uri..Station8UriStream URIs for radio stations 1 to 8.
