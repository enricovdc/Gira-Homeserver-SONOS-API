1.Description

Controls one Sonos player over the local network using the players UPnP and SOAP API on port 1400. Provides playback control (play, pause, stop, next, previous), volume and mute, Sonos Admin preset library, status outputs (state, volume, mute, title, artist, active station), and live UPnP event push so status outputs update without polling.
Compatible with current and 2026 Sonos firmware. Direct-stream presets use empty DIDL-Lite metadata and the x-rincon-mp3radio direct-broadcast scheme, with an automatic fallback if the player rejects the first attempt.
Important
The node binds a TCP listener on port 8081 (or the next free port up to 8083) to receive UPnP NOTIFY callbacks from the players. The HomeServer must allow this port on the LAN interface. If binding fails the node falls back to timer-based status polling and still works.
Note
Add one instance per Sonos player. Each instance must have a unique Host. All instances share one NOTIFY listener thread.

2.Inputs

E#NameInitDescription
E1HostPlayer identifier. UUID (e.g. RINCON_xxx) is strongly preferred because it is stable across firmware updates and DHCP renumbering. MAC address, custom name from the Admin block, or a literal IPv4 also accepted. Required.
E2Play0Rising edge starts or resumes playback.
E3Pause0Rising edge pauses playback.
E4Stop0Rising edge stops playback.
E5Next0Rising edge skips to next track.
E6Prev0Rising edge skips to previous track.
E7SetVolume0Absolute volume 0 to 100.
E8VolUp0Rising edge increases volume by VolStep.
E9VolDown0Rising edge decreases volume by VolStep.
E10SetMute00 unmutes, non-zero mutes.
E11MuteToggle0Rising edge toggles mute.
E12SetShuffle00 = shuffle off, non-zero = shuffle on. Combined with SetRepeat to compose the Sonos PlayMode (NORMAL / REPEAT_ALL / SHUFFLE_NOREPEAT / SHUFFLE). Changing one input leaves the other intact.
E13SetRepeat00 = repeat off, non-zero = repeat-all. REPEAT_ONE is not exposed separately — it surfaces on the RepeatState output as 1 when set from the Sonos app.
E14StartRadio0Alphabetical index 1..N of a preset from the Sonos Admin library (Sonos Admin block required). The # column in the Admin's Presets table shows each preset's current index.
E15StartRadioNamePreset name (case-insensitive) from the Sonos Admin library. Use this when binding to a Gira visualisation dropdown or text input where the name is more convenient than tracking an index.
E16GroupPreset0Form a Sonos zone group from a predefined preset (Admin's Group presets section). Alphabetical index 1..N. The trigger Player block needn't be the master — master + members come from the Admin definition.
E17GroupPresetNameForm a group preset by name (case-insensitive).
E18Ungroup0Rising edge — break THIS player out of its current zone group. Other group members keep playing on the master.
E19Resubscribe0Rising edge clears UPnP subscriptions and re-subscribes.
E20VolStep2Step size for VolUp and VolDown.
E21PollInterval60Status poll interval in seconds. Leave at 0 to use the Admin web UI's Player Defaults value.
E22SubTimeout1800UPnP subscription timeout granted to the player. Leave at 0 to use the Admin web UI's Player Defaults value.
E23HttpTimeout5HTTP request timeout in seconds. Leave at 0 to use the Admin web UI's Player Defaults value.
E24CallbackBaseCallback base URL for UPnP. Leave empty to use the Admin web UI's Player Defaults value, or fall through to auto-detection from the HomeServer's LAN IP.

3.Outputs

A#NameInitSBCDescription
A1ZoneNameyesThe Sonos zone name as configured in the Sonos app (e.g. "Living Room"). Updated on every Tick by fetching <roomName> from the player's UPnP device description — so renames in the Sonos app surface here within one poll interval.
A2Online0yes1 when the player responded recently.
A3StateyesFriendly playback state: Playing / Paused / Stopped / Transitioning / Buffering / Connecting / No media / Playing TV / Playing line-in.
A4IsPlaying0yes1 when State == "Playing", else 0. Mutually exclusive with the other Is* flags. Convenient for KNX group address routing without parsing the string.
A5IsPaused0yes1 when State == "Paused", else 0.
A6IsStopped0yes1 when State == "Stopped", else 0.
A7IsTransitioning0yes1 when State == "Transitioning", else 0. Brief — Sonos passes through this when starting / changing tracks.
A8Volume0yesCurrent volume 0 to 100.
A9Mute0yesCurrent mute state.
A10TitleyesCurrent track title or live radio stream content.
A11ArtistyesCurrent artist if available.
A12AlbumyesCurrent album. Empty for radio streams that have no album metadata.
A13AlbumArtURIyesCover-art URL ready to be embedded in a Gira visualisation tile. Relative paths from Sonos (e.g. /getaa?u=...) are converted to absolute (http://<player-ip>:1400/getaa?...).
A14ShuffleState0yes1 when the player is in any SHUFFLE play mode. Reflects the SetShuffle input and any change made from the Sonos app.
A15RepeatState0yes1 when the player is in REPEAT_ALL or REPEAT_ONE. Reflects the SetRepeat input and any change made from the Sonos app.
A16GroupInfoyesEmpty when this player is the coordinator or standalone. When this player is a slave: the master's Zone Name (resolved via the Admin registry when possible), else the master's RINCON UUID.
A17IsCoordinator1yes1 when this player is the group coordinator (or standalone), 0 when it is a slave member. Detected by inspecting the CurrentTrackURI — slaves have x-rincon:<master-uuid>.
A18ActiveStation0yesIndex of the last preset started.
A19LastErroryesLast error code from the player or HTTP layer.
A20Subscribed0yes1 when both UPnP subscriptions are healthy.
