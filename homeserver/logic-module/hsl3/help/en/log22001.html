1.Description

Singleton companion node that starts an HTTP server inside HSL3 and serves a web administration UI for the Sonos integration. The UI lets the end user manage discovered and manually-added Sonos players (identified by IP and/or MAC), maintain a global preset library (radio, favorites, playlists, line-in sources), and configure Sonos Cloud Control API credentials with OAuth authorization without leaving the HomeServer.
The node runs both periodic and KNX-triggerable SSDP discovery. The latest scan result is emitted as a newline-separated ip;uuid;model list on DiscoveredPlayers and a numeric count on LastDiscoveryCount, suitable for direct KNX wiring or HS visualisation widgets.
The node maintains a class-level player registry that LBS 22000 Sonos Player consults whenever its Host input is a friendly name or a MAC address instead of a literal IP. This makes configured player references survive DHCP renumbering on networks that don't reserve addresses.
Note
LBS 22000 still works standalone when this Admin node is absent. Add the Admin node when you want the web UI, KNX-triggerable discovery, the shared station library, or DHCP-resilient player references.
Important
The node binds a TCP listener on port 8080 (or next free up to 8083). The web UI is unauthenticated and should not be exposed beyond the LAN.

2.Inputs

E#NameInitDescription
E1HttpPort8080Preferred admin HTTP port. Falls back to 8081-8083 if busy.
E2AutoDiscoverInterval300Periodic SSDP rescan interval in seconds. Minimum 60.
E3TriggerDiscovery0Rising edge starts an immediate SSDP scan. Wire to a KNX button for on-demand discovery.
E4DiscoveryTimeout4Per-scan SSDP wait time in seconds.
E5CloudClientIdSonos developer client ID. Optional; the UI can also set this.
E6CloudClientSecretSonos developer client secret. Optional.
E7OAuthRedirectBaseExternal URL the HomeServer is reachable at, e.g. http://192.168.1.10:8080. OAuth callback is at this URL + /oauth/callback.
