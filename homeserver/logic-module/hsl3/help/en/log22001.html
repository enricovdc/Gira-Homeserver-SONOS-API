1.Description

Performs an SSDP M-SEARCH on the LAN to find every Sonos player reachable from the HomeServer. Emits a newline separated list on the Result output of the form ip;uuid;model, one row per player.
Note
Use this node once at commissioning time to populate the Host input on each Sonos Player node. SSDP only works on the same broadcast domain as the players; multi-VLAN setups need an IGMP proxy or pre-configured player IPs.

2.Inputs
