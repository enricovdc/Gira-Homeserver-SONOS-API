1.Beschreibung

Optionaler Begleitbaustein pro Player zum LBS 22000 Sonos Player. Enthaelt die Klang-Feineinstellungen, die nicht auf jedem Sonos-Baustein noetig sind: Bass / Hoehen, Loudness, Soundbar-EQ (Nachtmodus + Sprachmodus), Crossfade und Sleep-Timer. Eine Instanz pro Player auf die Canvas legen, der diese Extras braucht.
Der Player-Baustein (LBS 22000) behaelt die primaere Wiedergabesteuerung. Dieser Baustein ist rein additiv — fuer Kueche / Schlafzimmer, die nur Play / Pause / Lautstaerke per KNX brauchen, weglassen.
Hinweis
Nur Polling, keine UPnP-Abonnements. Diese Einstellungen aendern sich selten; Aktualisierung im gleichen Tick-Takt wie der Player (Vorgabe 60 s) reicht. Soundbar-EQs (Nachtmodus, Sprachmodus) scheitern sauber auf Nicht-Soundbar-Hardware mit NIGHTMODE_UNSUPPORTED / DIALOGMODE_UNSUPPORTED auf LastError.

2.Eingaenge

E#NameInitBeschreibung
E1HostPlayer-Kennung. Gleicher Wert wie beim passenden LBS 22000 (UUID empfohlen). Der Admin-Baustein loest UUID / MAC / Name / IP zur aktuellen Player-IP auf.
E2SetBass0Bass-Anpassung -10 bis +10. Wird auf den Bereich begrenzt. Bestaetigung erfolgt ueber den Bass-Ausgang nach erfolgreichem SOAP.
E3SetTreble0Hoehen-Anpassung -10 bis +10. Gleiche Begrenzung wie SetBass.
E4SetLoudness0Loudness-Kontur. 0 aus, nicht 0 ein. Besonders sinnvoll bei niedriger Hoerlautstaerke.
E5SetNightMode0Soundbar-Nachtmodus (Dynamikkompression fuer spaeten TV-Genuss). Funktioniert nur auf Beam / Arc / Playbar. Andere Player schreiben NIGHTMODE_UNSUPPORTED auf LastError.
E6SetDialogMode0Soundbar-Sprachmodus / Dialog-Anhebung. Gleiche Einschraenkung wie SetNightMode; nicht-Soundbar schreibt DIALOGMODE_UNSUPPORTED.
E7SetCrossfade0Crossfade zwischen Queue-Titeln. 0/1. Nur sinnvoll bei Queue / Playlist-Wiedergabe (Radio ignoriert es).
E8SetSleepTimer0Sleep-Timer in Minuten (0 bricht ab).
E9SetTVMode0Flanke schaltet die Soundbar auf den physischen TV-Eingang (Beam / Arc / Playbar / Ray). URI x-sonos-htastream:<UUID>:spdif. Nicht-Soundbar schreibt NO_HT_STREAM. Zurueck zur Musik: ein Preset auf LBS 22000 ausloesen.
E10SetLED0Status-LED 0/1. Praktisch fuer Kino-Szenen.
E11SetGroupVolume0Gruppen-Lautstaerke proportional setzen (0-100). Nur am Gruppen-Koordinator wirksam — Slaves schreiben GROUP_NOT_COORDINATOR.
E12SetSurroundEnable0Surround-Kanaele ein/aus. Nicht-Soundbar: SURROUND_UNSUPPORTED.
E13SetSurroundLevel0Surround-Pegel -15 bis +15. Wird begrenzt.
E14SetSubEnable0Subwoofer ein/aus. Nicht-unterstuetzt: SUB_UNSUPPORTED.
E15SetSubGain0Subwoofer-Pegel -15 bis +15.
E16SetTrueplay0Trueplay-Kalibrierung anwenden ein/aus. Neue Kalibrierung nur per Sonos-iOS-App. TRUEPLAY_UNAVAILABLE wenn keine Kalibrierung vorhanden.
E17PollInterval0Status-Abfrageintervall in Sekunden. Bei 0 wird der Wert aus der Admin-Webseite (Player Defaults) verwendet.
E18HttpTimeout0HTTP-Timeout in Sekunden. Bei 0 wird der Wert aus der Admin-Webseite verwendet.
