1.Beschreibung

Steuert einen einzelnen Sonos Player ueber das lokale Netzwerk mittels der UPnP und SOAP API auf Port 1400. Bietet Wiedergabesteuerung (Play, Pause, Stop, Naechster, Vorheriger), Lautstaerke und Stummschaltung, Sonos Admin Preset-Bibliothek, Statusausgaenge (Zustand, Lautstaerke, Stumm, Titel, Interpret, aktiver Preset) und Live UPnP Event Push so dass Statusausgaben ohne Polling aktualisiert werden.
Kompatibel mit aktueller und 2026er Sonos Firmware. Der Preset-Start verwendet leere DIDL-Lite Metadaten und das x-rincon-mp3radio Direkt-Broadcast-Schema mit automatischem Fallback bei Ablehnung.
Wichtig
Der Baustein oeffnet einen TCP Listener auf Port 8081 (oder dem naechsten freien Port bis 8083) fuer den Empfang von UPnP NOTIFY Callbacks. Der HomeServer muss diesen Port am LAN Interface erlauben. Bei Fehlschlag schaltet der Baustein auf Timer-basiertes Status-Polling um und funktioniert weiterhin.
Hinweis
Fuegen Sie eine Instanz pro Sonos Player hinzu. Jede Instanz benoetigt einen eindeutigen Host. Alle Instanzen teilen sich einen NOTIFY Listener Thread.

2.Eingaenge

E#NameInitBeschreibung
E1HostPlayer-Kennung. UUID (z.B. RINCON_xxx) wird dringend empfohlen, da diese auch ueber Firmware-Updates und DHCP-Adresswechsel stabil bleibt. MAC-Adresse, eigener Name aus dem Admin-Baustein oder eine literale IPv4 werden ebenfalls akzeptiert. Pflichtfeld.
E2Play0Steigende Flanke startet oder setzt Wiedergabe fort.
E3Pause0Steigende Flanke pausiert.
E4Stop0Steigende Flanke stoppt.
E5Next0Naechster Titel.
E6Prev0Vorheriger Titel.
E7SetVolume0Absolute Lautstaerke 0 bis 100.
E8VolUp0Lauter um VolStep.
E9VolDown0Leiser um VolStep.
E10SetMute00 unmute, nicht 0 mute.
E11MuteToggle0Schaltet Stummschaltung um.
E12SetShuffle00 = Zufallswiedergabe aus, ungleich 0 = ein. Wird zusammen mit SetRepeat zum Sonos-PlayMode (NORMAL / REPEAT_ALL / SHUFFLE_NOREPEAT / SHUFFLE) kombiniert. Das Aendern eines Eingangs laesst den anderen unveraendert.
E13SetRepeat00 = Wiederholung aus, ungleich 0 = Wiederholung Alle. REPEAT_ONE wird nicht separat angeboten — RepeatState wird trotzdem 1 wenn aus der Sonos-App so eingestellt.
E14StartRadio0Alphabetischer Index 1..N eines Presets aus der Sonos Admin Preset-Bibliothek. Die Spalte # in der Admin-UI zeigt den aktuellen Index.
E15StartRadioNamePreset-Name (Gross-Klein-egal) aus der Sonos Admin Bibliothek. Praktisch fuer Bindung an Gira Visualisierungs-Auswahl oder Textfeld.
E16GroupPreset0Bildet eine Sonos-Zonengruppe nach Vorlage aus dem Admin-Baustein. Alphabetischer Index 1..N. Master + Members kommen aus der Admin-Definition.
E17GroupPresetNameGruppen-Preset per Name bilden (Gross-Klein-egal).
E18Ungroup0Steigende Flanke loest diesen Player aus seiner aktuellen Zonengruppe.
E19Resubscribe0Erneuert die UPnP Abonnements.
E20VolStep2Schrittweite fuer VolUp und VolDown.
E21PollInterval60Status-Abfrageintervall in Sekunden. Bei 0 wird der Wert aus der Admin-Webseite (Player Defaults) verwendet.
E22SubTimeout1800UPnP Abonnement Timeout. Bei 0 wird der Wert aus der Admin-Webseite verwendet.
E23HttpTimeout5HTTP Anfrage Timeout in Sekunden. Bei 0 wird der Wert aus der Admin-Webseite verwendet.
E24CallbackBaseCallback Basis URL. Leer = Admin-Vorgabe verwenden, sonst Auto-Erkennung anhand der HomeServer-LAN-IP.

3.Ausgaenge

A#NameInitSBCBeschreibung
A1ZoneNamejaSonos-Zonenname aus der Sonos-App (z.B. "Wohnzimmer"). Wird bei jedem Tick aus <roomName> des Players gelesen, so dass Umbenennungen aus der Sonos-App innerhalb eines Polling-Intervalls erscheinen.
A2Online0ja1 wenn der Player kuerzlich antwortete.
A3StatejaLesbarer Wiedergabestatus: Playing / Paused / Stopped / Transitioning / Buffering / Connecting / No media / Playing TV / Playing line-in.
A4IsPlaying0ja1 wenn State == "Playing", sonst 0. Gegenseitig ausschliessend mit den anderen Is*-Flags. Praktisch zum direkten Routen auf KNX-Gruppenadressen ohne den String zu parsen.
A5IsPaused0ja1 wenn State == "Paused", sonst 0.
A6IsStopped0ja1 wenn State == "Stopped", sonst 0.
A7IsTransitioning0ja1 wenn State == "Transitioning", sonst 0. Kurzer Uebergang beim Start oder Wechsel.
A8Volume0jaAktuelle Lautstaerke.
A9Mute0jaStummschaltung.
A10TitlejaTitel oder Stream-Inhalt.
A11ArtistjaInterpret.
A12AlbumjaAktuelles Album. Leer bei Radiostreams ohne Album-Metadaten.
A13AlbumArtURIjaURL des Albumcovers, direkt fuer eine Gira-Visualisierungs-Kachel verwendbar. Relative Sonos-Pfade (z.B. /getaa?u=...) werden zu absoluten (http://<player-ip>:1400/getaa?...) ergaenzt.
A14ShuffleState0ja1 wenn der Player in einem SHUFFLE-Modus ist. Spiegelt SetShuffle und auch direkt in der Sonos-App vorgenommene Aenderungen.
A15RepeatState0ja1 wenn der Player in REPEAT_ALL oder REPEAT_ONE ist. Spiegelt SetRepeat und Aenderungen aus der Sonos-App.
A16GroupInfojaLeer wenn dieser Player Koordinator oder alleinstehend ist. Wenn dieser Player Slave ist: Zonen-Name des Masters (ueber Admin-Registry aufgeloest), sonst RINCON-UUID des Masters.
A17IsCoordinator1ja1 wenn dieser Player Gruppen-Koordinator (oder alleinstehend) ist, 0 wenn Slave. Wird aus der CurrentTrackURI ermittelt — Slaves haben x-rincon:<master-uuid>.
A18ActiveStation0jaIndex des zuletzt gestarteten Presets.
A19LastErrorjaLetzter Fehlercode.
A20Subscribed0ja1 wenn beide UPnP Abonnements aktiv sind.
