1.Description

Optional per-player companion to LBS 22000 Sonos Player. Carries the sound-tuning controls that aren't needed on every Sonos block: bass / treble, loudness, soundbar EQ (Night Mode + Dialog Mode), crossfade, and the sleep timer. Drop one instance onto the canvas for any speaker that needs the extras.
The Player block (LBS 22000) keeps all primary playback control. This block is purely additive — leave it off for kitchens / bedrooms that just want play / pause / volume from KNX.
Note
Polling-only, no UPnP subscriptions. These settings change rarely, so refreshing on the same Tick cadence as the Player (default 60 s) is enough. Soundbar EQ controls (Night Mode, Dialog Mode) fail gracefully on non-soundbar hardware with NIGHTMODE_UNSUPPORTED / DIALOGMODE_UNSUPPORTED on LastError.

2.Inputs

E#NameInitDescription
E1HostPlayer identifier. Same value used on the matching LBS 22000 (UUID preferred). The Admin LBS resolves UUID / MAC / name / IP to the current player IP.
E2SetBass0Bass adjustment -10 to +10. Clamped to range; values outside are silently saturated. Confirms via Bass output after a successful SOAP call.
E3SetTreble0Treble adjustment -10 to +10. Same clamping as SetBass.
E4SetLoudness0Loudness contour. 0 = off, non-zero = on. Particularly useful at low listening volumes where Sonos's low-end falls off otherwise.
E5SetNightMode0Soundbar Night Mode (loudness compression for late-night TV). Works only on Beam / Arc / Playbar. Non-soundbar players write NIGHTMODE_UNSUPPORTED to LastError.
E6SetDialogMode0Soundbar Dialog Mode / Speech Enhance. Same constraint as SetNightMode; non-soundbar players write DIALOGMODE_UNSUPPORTED.
E7SetCrossfade0Crossfade between tracks in a queue. 0/1. Only meaningful while the player is playing from a queue / playlist (radio streams ignore it).
E8SetSleepTimer0Sleep timer in minutes (0 cancels). Sonos stops playback when the timer reaches zero. SleepTimerRemaining output reflects the countdown.
E9SetTVMode0Rising edge engages the soundbar's physical TV input (Beam / Arc / Playbar / Playbase / Ray). URI is built as x-sonos-htastream:<UUID>:spdif from the player's RINCON UUID (looked up via Admin). Non-soundbar players surface NO_HT_STREAM on LastError. To return to music, trigger a preset on LBS 22000.
E10SetLED0Status LED. 0 = off, 1 = on. Useful for "cinema mode" scenes that turn LEDs off in every room.
E11SetGroupVolume0Set the entire zone group's volume proportionally (0-100). Works only on the group coordinator — slaves write GROUP_NOT_COORDINATOR to LastError. Wire to the LBS 22002 of the coordinator speaker.
E12SetSurroundEnable0Enable surround channels (soundbar with surround pair). 0/1. Non-supporting hardware surfaces SURROUND_UNSUPPORTED.
E13SetSurroundLevel0Surround channel level -15 to +15. Clamped at the input boundary.
E14SetSubEnable0Enable the connected Sub. 0/1. Non-supporting hardware surfaces SUB_UNSUPPORTED.
E15SetSubGain0Sub gain -15 to +15. Useful for nightly "low bass" scene.
E16SetTrueplay0Enable / disable applying the stored Trueplay room calibration. 0/1. Running a new calibration is iOS-only — this just toggles whether the profile is applied. TRUEPLAY_UNAVAILABLE on LastError if no calibration has been performed yet.
E17PollInterval0Status poll interval in seconds. Leave at 0 to use the Admin web UI's Player Defaults value (default 60 s).
E18HttpTimeout0HTTP request timeout in seconds. Leave at 0 to use the Admin web UI's Player Defaults value (default 5 s).
